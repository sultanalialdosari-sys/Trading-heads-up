# 🔔 التنبيه المبكر — أسهم أمريكية تحت 5$

نظام يفحص السوق الأمريكي **كل 15 دقيقة أثناء الجلسة** على GitHub Actions (مجاناً)، ويرسل تنبيهاً على تيليجرام
**قبل** اختراق المقاومة فقط، عندما يستوفي سهم القواعد. لا يرسل أي أمر تداول — عميل Alpaca للقراءة فقط.
التنبيه ليس توصية شراء، والنظام لا يكتشف كل انفجار.

## ماذا يفعل في كل فحص
1. يمسح كل الأسهم المدرجة (NASDAQ / NYSE / AMEX، بدون OTC) — بيانات السوق الكامل **متأخرة 15 دقيقة**.
2. يختار قائمة قصيرة (≈60 سهماً تحت 5$ بحجم دولاري كافٍ ولم تتحرك كثيراً بعد).
3. يحلل شموع 5 دقائق: السوق الكامل حتى قبل 16 دقيقة + IEX لآخر 16 دقيقة (السعر اللحظي من IEX فقط).
4. للمؤهلين فقط: إفصاحات SEC (طرح أسهم، شطب، تجميع عكسي) والأخبار (جوهري / ترويجي / مخاطرة).
5. يرسل التنبيه، ويفتح صفقتين افتراضيتين (500 سهم):
   - **A** دخول عند التنبيه، **B** أمر معلّق لا يُنفَّذ إلا إذا اخترق السعر مستوى الدخول.
   - وطريقة **مقارنة**: أي سهم تحت 5$ قفز حجمه في نفس الوقت، بنفس قواعد الخروج.
6. يتابع: «✅ تفعّلت» عند الاختراق أو «❌ أُلغيت» عند كسر مستوى الإبطال — رسالة واحدة لكل حالة.
7. بعد الإغلاق: يغلق الصفقات، يسجل **ما فات** (أسهم ارتفعت 30%+ بلا تنبيه ولماذا)، ويرسل ملخص اليوم.

## ملف الإعدادات config.json (الإصدار 3)
ملف واحد يقرؤه النظام الحي وخط البحث، ويُتحقق منه قبل كل تشغيل (`hu/config.py`):
- `live` قواعد التنبيه الحالية (الجدول أدناه) · `paper` حجم الصفقة الورقية · `universe` `filters` `exits` `costs` `execution` `validation` إعدادات البحث.
- **يتوقف التشغيل** برسالة واضحة في سجل Actions إذا: `live_orders` ليست false، أو وُجد مفتاح/سر داخل الملف، أو مفتاح غير معروف (خطأ إملائي)، أو بدأ الاختبار قبل نهاية التدريب، أو رُتبت التكاليف خطأ (متفائل ≤ أساسي ≤ متشائم).
- بصمة الملف (sha256) تُحفظ مع كل تشغيل في جدول `runs.config_hash`، فنعرف أي إعدادات أنتجت كل نتيجة.
- الملف القديم المسطح ما زال مقبولاً ويُرحَّل تلقائياً إلى `live`.
- قيم البحث أمثلة بدائية للانطلاق، لا نتائج مثبتة.

## الرسوم البيانية (TradingView Lightweight Charts)
قسم «الرسوم البيانية» في الموقع: شموع 5 دقائق بتوقيت الرياض لكل سهم فيه تنبيه أو صفقة افتراضية (عدا صفقات المقارنة)، مع خطوط التفعيل والإبطال والدخول والهدف، وشارات التنبيه والدخول والخروج.
- الشموع تُحفظ في جدول `chart_bars` من البيانات التي يجلبها النظام أصلاً، ويُكمل اليوم من SIP بعد الإغلاق (طلب مجمّع واحد). الأيام الناقصة تُكمل تلقائياً، أو يدوياً: Actions ← headsup ← mode = charts.
- المكتبة نسخة مثبتة داخل المستودع: `docs/vendor/lightweight-charts.standalone.production.js` (الإصدار 5.3.0، Apache-2.0، © TradingView, Inc.) مع الترخيص وإشعار النسبة، وشعار TradingView ظاهر على كل رسم كما يشترط الترخيص.

## مخزن البيانات نقطي الزمن (pit/)
بيانات البحث بلا نظر للمستقبل وبلا انحياز للناجين. يُبنى يدوياً من Actions ← **pit-data** ← Run workflow، ويُنشر كـ Release باسم `pit-data`.
- **يومي منذ 2016** لكل سهم كان سعره الخام ≤ 7.5$ في أي يوم، بما فيها الأسهم المشطوبة. الشمعة اليومية لا تُرى قبل 16:00 نيويورك.
- **التجميع العكسي** مستنتج من الفرق بين السعر الخام والمعدل؛ فلتر «تحت 5$» على الخام دائماً.
- **SEC:** كل إفصاح يُعرف عند وقت قبوله + 10 دقائق (الساعة تُقرأ بتوقيت نيويورك دائماً — التفسير الأحوط). الأسهم القائمة تُعرف عند قبول الإفصاح الذي حملها، وتُصحح بأي تجميع بعدها.
- **حدود معروفة:** ربط الرمز بشركة SEC متاح للأسهم النشطة فقط (قائمة SEC حالية)، فميزات SEC ناقصة للمشطوبة — النسبة في `manifest.json`. الرمز المعاد استخدامه يُعلَّم `symbol_shared`.
- الكود يقرأ البيانات عبر `store.view(as_of)` فقط؛ الاختبارات (`tests/test_pit.py`) تتحقق أن لا سجل بعد لحظة القرار يمر.

## التركيب (مرة واحدة، بدون أي تكلفة)
1. **حساب GitHub** مجاني من github.com.
2. **مستودع جديد** (New repository):
   - **Public** إذا تريد الموقع (GitHub Pages المجاني يعمل على المستودعات العامة فقط). المفاتيح تبقى سرية في الحالتين.
   - **Private** إذا لا تريد أن يرى أحد المرشحين والصفقات — بدون موقع، والتنبيهات تصلك على تيليجرام.
3. **ارفع الملفات:** Add file ← Upload files ← اسحب كل محتويات المجلد (بما فيها مجلد `.github`) ← Commit.
   - إذا لم يُرفع مجلد `.github`: Add file ← Create new file ← اكتب الاسم `.github/workflows/headsup.yml` والصق محتوى الملف.
4. **الأسرار:** Settings ← Secrets and variables ← Actions ← New repository secret — أضف خمسة:
   | الاسم | القيمة |
   |---|---|
   | `ALPACA_API_KEY` | مفتاح Alpaca (Paper) |
   | `ALPACA_API_SECRET` | السر |
   | `TELEGRAM_TOKEN` | توكن البوت (نفس بوت تطبيق تداولي يعمل) |
   | `TELEGRAM_CHAT_ID` | رقم المحادثة |
   | `SEC_USER_AGENT` | اسمك وبريدك، مثل: `Rayan rayan@example.com` (SEC تشترط ذلك) |
5. **صلاحية الحفظ:** Settings ← Actions ← General ← Workflow permissions ← **Read and write permissions** ← Save.
6. **الموقع (للمستودع العام):** Settings ← Pages ← Build and deployment ← Source: **GitHub Actions** (لا تختر Deploy from a branch).
   النظام ينشر الموقع بنفسه بعد كل فحص. الرابط يظهر في نفس الصفحة بعد أول تشغيل: `https://اسمك.github.io/اسم-المستودع/`
7. **تجربة فورية:** Actions ← headsup ← Run workflow. خارج الجلسة سيسجل «السوق مغلق» فقط — هذا طبيعي.

لا تلصق المفاتيح في أي محادثة أو ملف. مكانها الوحيد هو GitHub Secrets.

**كيف يعمل التشغيل:** GitHub يُسقط كثيراً من التشغيلات المجدولة المتقاربة (في أول يوم تشغيل نفّذ 3 فقط من حوالي 10).
لذلك صار `loop.py` يعمل كتشغيل واحد طويل (حتى 5 ساعات و40 دقيقة) ويفحص في المواعيد بنفسه، وعدة مواعيد بداية في اليوم
تتسلّم من بعضها. قاعدة البيانات تُحفظ في فرع اسمه **data** (لا في main)، والموقع يُنشر من `site.yml` كل 10 دقائق تقريباً وفوراً عند أي تنبيه.

**ما قبل الافتتاح وبعد الإغلاق:** أسهم تحت 5$ تحركت 8%+ عن آخر إغلاق بحجم دولاري حقيقي وبقيت قرب قمتها.
تدخل «قائمة مراقبة» للجلسة التالية: التفعيل = اختراق قمة تلك الفترة أثناء الجلسة، والنتيجة (وصفقة افتراضية معلّقة) تُقاس من الجلسة فقط.
